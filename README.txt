============================================================
  X6 Conlang Translator (Nikki Conlang Forge) 使用说明
============================================================

一、快速开始
------------------------------------------------------------

1. 双击 X6_Conlang_Translator.exe 启动程序
2. 首次运行将在 exe 同级目录自动创建以下文件/文件夹：
   - data/            数据存储目录（语言资料、翻译历史等）
   - data/config.json 项目配置文件
   - app_config.json  PaperHub AI 配置文件
3. 程序启动后即可开始使用

二、目录结构
------------------------------------------------------------

X6_Conlang_Translator/
├── X6_Conlang_Translator.exe    主程序
├── data/                        数据目录（自动创建）
│   ├── config.json              项目配置
│   ├── app_config.json          AI 配置（旧位置，已迁移）
│   └── languages/               各语言子目录
│       └── <语言名>/            每种语言一个子文件夹
│           ├── whitepaper.md    白皮书
│           ├── Conlang_Master_Library.json  主词典
│           ├── Mapping_Rules.csv           映射规则
│           └── Translation_History.json    翻译历史
├── app_config.json              PaperHub AI 配置（exe旁边）
└── README.txt                   本文件

三、功能说明
------------------------------------------------------------

1. 语言管理
   - 在左侧列表中选择/创建/删除语言
   - 每种语言独立管理白皮书、词典、映射规则

2. 翻译功能
   - 单句翻译：输入原文 → 规则引擎翻译 → 输出人造语
   - 批量翻译：导入 Excel → 批量翻译 → 导出结果
   - PaperHub AI 辅助翻译（需在设置中配置 API Key）

3. TTS 语音合成
   - 自动生成 SSML 语音标注
   - 支持情感（喜/怒/哀/惧/平静/紧急）+ 体态 + 年龄叠加

4. 词典管理
   - 添加新词到词典
   - 导入/导出词典数据
   - 未匹配词报告

四、更新说明
------------------------------------------------------------

本软件预留了更新接口。后续版本更新时：
1. 下载新版本的 X6_Conlang_Translator.exe
2. 替换旧版 exe 文件
3. data 目录和 app_config.json 会被自动保留和兼容

配置文件格式向前兼容，新版本会自动补全新增配置字段。

五、界面定制说明
------------------------------------------------------------

本软件预留了界面设计接口。界面主题在 app/ui_theme.py 中定义：
- 调色板颜色
- 字体大小
- 组件样式

后续界面重新设计时，只需修改 ui_theme.py 即可全局生效。

六、常见问题
------------------------------------------------------------

Q: 双击 exe 无法启动？
A: 检查是否被杀毒软件拦截，添加信任后重试。
   Windows 可能首次运行较慢（解压临时文件）。

Q: 翻译结果不正确？
A: 检查白皮书、词典、映射规则是否完整导入。

Q: PaperHub AI 翻译无法使用？
A: 需在"设置 → PaperHub 设置"中填写有效的 API Key。

Q: 如何备份数据？
A: 复制整个 data 目录即可。
