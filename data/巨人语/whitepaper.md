## 一、种族生理建模

### 1.1 种族起源与特征

巨人族是信念森林的特有种族之一，是信念森林的原生智慧物种。他们并非魔法生物或神明眷属，没有天生的驾驭魔法的能力。巨人诞生时，龙族已在信念森林中生活，各类巨兽也已栖息于此。

巨人族的体型庞大，大约是正常人类的数倍。这种体型天然地适应信念森林的自然环境。其物理力量水平远高于人类，能够移动或摧毁更庞大和坚硬的事物。

> **关键气质：** 智慧、勤劳、自信、进取。巨人不是奇幻作品中常见的"武力强于智力"的笨拙巨人，而是拥有澎湃自信和热情幻想的智慧种族，代表着人类适应自然、利用自然、改造自然的野心。

### 1.2 发声器官特征

基于其巨大体型和独特生理构造，巨人族的发声系统具有以下特征：

| 特征 | 描述 | 语言学影响 |
|------|------|-----------|
| **巨大共鸣腔** | 喉部、咽腔、胸腔共鸣空间远超人类 | 声音极度低沉浑厚，基频低，泛音丰富 |
| **长而厚的声带** | 声带长度和厚度随体型等比增大 | 音域偏低，高音受限，低音极为饱满 |
| **大容积肺部** | 肺活量远超人类 | 支持长句一口气完成，停顿极少 |
| **宽大口腔** | 口腔共鸣腔极大 | 元音偏后、偏低，前高元音受限 |
| **较弱的精细控制** | 大体型不利于细微精密的舌位变化 | 辅音偏"硬、直、清晰"，无软腭化、无腭化 |

### 1.3 种族气质对话音的影响

巨人族的族群气质直接塑造了其语言风格：

| 族群气质 | 语言表现 |
|---------|---------|
| **智慧与自信** | 陈述句语气笃定，语速从容不迫，无犹豫停顿 |
| **勤劳与进取** | 语句结构直接高效，极少冗余修饰和虚词 |
| **祖先崇拜** | 仪式语言庄严缓慢，富含敬语和呼格结构 |
| **集体意识** | 第一人称复数使用频率远高于单数 |
| **务实主义** | 词汇偏具体、可操作，抽象概念往往借用具体意象 |
| **非好战** | 语言中缺乏攻击性修辞，战争词汇多为防御性 |

## 二、语言定位与设计目标

### 2.1 语言背景

巨人语是巨人种族的古代语言。随着落幕之日巨人族的灭绝，该语言已不再有活体母语者，仅存于遗迹碑文、残卷和古代铭文中。

### 2.2 风格基底

- **古拉丁语骨架：** 借鉴古拉丁语的语音体系与构词逻辑，赋予语言古典、庄严的气质
- **古希腊式庄严感：** 融合古希腊语的仪式感和哲学表达方式
- **低元音强化：** 以 a / u 为主导元音，营造"厚重、低沉、仪式感强"的听觉印象

### 2.3 使用场景

| 场景 | 说明 |
|------|------|
| **遗迹铭文** | 石碑、建筑铭刻、墓志铭 |
| **咒语吟唱** | 仪式咒语、召唤咒文 |
| **古代记录残片** | 考古文献、历史记载、工程蓝图 |
| **NPC 发声** | 非日常态，特殊剧情或仪式场景中的巨人语音 |

### 2.4 核心设计原则

1. **可读性 > 真实性：** 对拉丁语进行简化，确保团队成员可拼读
2. **音感统一：** 偏 a / u 低元音，建立一致的听觉辨识度
3. **可组合性强：** 模块化词组设计，支持批量生成语料
4. **仪式感优先：** 语速缓慢、音节分明、韵律感强

## 三、音系学推导（IPA 音位表）

### 3.1 设计原则

巨人语音系设计遵循三条核心原则：

1. **拉丁语基底：** 借鉴古典拉丁语的发音体系，赋予语言厚重的历史感和庄严气质
2. **低元音主导：** 以 a / u 为核心元音，o 为辅助元音，i / e 边缘化，营造低沉、压迫性的听觉效果
3. **硬辅音特征：** 无英语式软音（如 /ʃ/、/ʒ/、/tʃ/），辅音"硬、直、清晰"，体现巨人的力量和自信

### 3.2 元音系统（Monophthongs）

巨人语拥有 **5 个单元音**，形成以低后元音为核心的不对称元音空间：

| 字母 | IPA | 发音描述 | 使用频率 | 示例词 |
|------|-----|---------|---------|--------|
| **A a** | /a/ | 前低不圆唇元音 | ★★★★★ 极高 | *grav*（重） |
| **U u** | /u/ | 后高圆唇元音 | ★★★★★ 极高 | *dus*（压） |
| **O o** | /ɔ/ | 后中圆唇元音 | ★★★★ 高 | *mort*（死） |
| **E e** | /ɛ/ | 前中不圆唇元音 | ★★★ 中 | *ten*（持） |
| **I i** | /ɪ/ | 近前近高不圆唇元音 | ★★ 低 | *vin*（绑） |

> **长音标记：** 在咒语或仪式文本中，元音可标记长音（ā / ū / ō / ē / ī），表示发音时长加倍。长音仅用于仪式场合，日常碑文中不出现。

### 3.3 双元音（Diphthongs）

巨人语的双元音系统较为有限，以低元音组合为主：

| 拼写 | IPA | 发音描述 | 使用频率 |
|------|-----|---------|---------|
| au | /aʊ/ | 由 /a/ 滑向 /ʊ/ | ★★★ 中 |
| ae | /aɪ/ | 由 /a/ 滑向 /ɪ/ | ★★ 低 |
| ua | /ʊa/ | 由 /ʊ/ 滑向 /a/ | ★★ 低 |

### 3.4 辅音系统（Consonants）

巨人语拥有 **13 个基本辅音**，发音"硬、直、清晰"：

#### 辅音表

| 发音方式 \ 发音部位 | 双唇 | 齿/龈 | 软腭 | 声门 |
|---------------------|------|-------|------|------|
| **塞音（清）** | p /p/ | t /t/ | c /k/ | |
| **塞音（浊）** | b /b/ | d /d/ | g /g/ | |
| **鼻音** | m /m/ | n /n/ | | |
| **擦音（清）** | | s /s/ | | h /h/ |
| **颤音** | | r /r/ | | |
| **边近音** | | l /l/ | | |
| **近音** | v /w/ | | | |

#### 辅音详表

| 字母 | IPA | 发音描述 | 备注 |
|------|-----|---------|------|
| **P p** | /p/ | 清双唇塞音 | 不送气，硬而短促 |
| **B b** | /b/ | 浊双唇塞音 | 低沉有力 |
| **T t** | /t/ | 清齿龈塞音 | 不送气，清晰利落 |
| **D d** | /d/ | 浊齿龈塞音 | 厚重 |
| **C c** | /k/ | 清软腭塞音 | 永远发 /k/，无软音变体 |
| **G g** | /g/ | 浊软腭塞音 | 永远发 /g/，无软音变体 |
| **M m** | /m/ | 双唇鼻音 | |
| **N n** | /n/ | 齿龈鼻音 | |
| **S s** | /s/ | 清齿龈擦音 | 永远清音，无 /z/ 变体 |
| **H h** | /h/ | 清声门擦音 | 轻微送气 |
| **R r** | /r/ | 齿龈颤音 | 大舌音/弹舌音，仪式语言中必须颤音 |
| **L l** | /l/ | 齿龈边近音 | |
| **V v** | /w/ | 双唇软腭近音 | 发 /w/ 而非 /v/，类似古典拉丁语 |

> **关键发音规则：**
> - **C 永远发 /k/：** 不存在 /s/、/tʃ/ 等软音变体。*centum* → /ˈkɛn.tum/（非 /ˈsɛn.tum/）
> - **G 永远发 /g/：** 不存在 /dʒ/ 等软音变体。*gloria* → /ˈglɔ.ri.a/（非 /ˈdʒlɔ.ri.a/）
> - **S 永远发 /s/：** 不存在 /z/ 变体。*rosa* → /ˈrɔ.sa/（非 /ˈrɔ.za/）
> - **V 发 /w/：** 如古典拉丁语。*vinculum* → /wɪnˈku.lum/

### 3.5 特殊辅音规则

#### 3.5.1 弹舌音 /r/（字母 R）

`r` 为齿龈颤音（大舌音），是仪式语言中的标志性音素，象征巨人的力量与威严。

- 在日常铭文中可简化为弹音（tap /ɾ/）
- 在正式仪式和咒语中，必须使用充分颤动的颤音（trill /r/）
- 颤音持续时间与语气强调程度成正比

#### 3.5.2 无软音原则

巨人语完全不包含以下英语式软音：

| 禁止的音 | 英语示例 |
|---------|---------|
| /ʃ/ | *sh*ip |
| /ʒ/ | mea*s*ure |
| /tʃ/ | *ch*ip |
| /dʒ/ | *j*udge |
| /θ/ /ð/ | *th*in / *th*is |

## 四、音节结构与音位配列

### 4.1 音节模板

巨人语的音节结构遵循以下模板：

```
(C)(C)V(C)
```

- **最小音节：** V（仅出现于词首元音）
- **最常见音节：** CVC
- **最大音节：** CCVC

### 4.2 常见音节组合

| 音节 | 类型 | 示例词 |
|------|------|--------|
| CV | 开音节 | *tu*（你） |
| CVC | 闭音节 | *dus*（压）、*tan*（持） |
| CCVC | 双辅音首 | *grav*（重）、*trac*（拉） |
| VC | 元音首 | *um*（与）、*en*（在） |

### 4.3 音位配列限制（Phonotactics）

#### 4.3.1 音节首（Onset）

- 允许单辅音：所有13个辅音均可
- 允许双辅音连缀（仅限以下组合）：
  - 塞音 + 近音/颤音/边音：/pr/、/br/、/tr/、/dr/、/cr/、/gr/、/pl/、/bl/、/cl/、/gl/
  - 擦音 + 近音/颤音/边音：/sr/、/sl/
  - 擦音 + 塞音：/st/、/sc/
- 禁止：三个及以上辅音连缀、鼻音+擦音连缀

#### 4.3.2 音节核（Nucleus）

- 任何单元音均可担任音节核
- 双元音仅出现在重读音节
- 在仪式文本中，长元音作为独立音节核

#### 4.3.3 音节尾（Coda）

- 允许单辅音结尾：/m/、/n/、/l/、/r/、/s/、/t/、/c/、/p/
- 双辅音结尾仅允许：/r/+塞音（/rt/、/rc/）、/l/+塞音（/lt/、/lc/）、鼻音+塞音（/nt/、/nc/、/mp/）
- 禁止：擦音结尾的双辅音组合

## 五、重音与韵律系统

### 5.1 重音规则

**标准规则：** 重音落在倒数第二音节（penultimate stress）。

| 示例词 | 音节划分 | 重音位置 | IPA（标重音） |
|--------|---------|---------|--------------|
| *Dusrath* | dus·rath | dus | /ˈdus.raθ/ → /ˈdus.rat/ |
| *Vulcruma* | vul·cru·ma | cru | /wul.ˈkru.ma/ |
| *Gigantum* | gi·gan·tum | gan | /gɪ.ˈgan.tum/ |
| *Malcura* | mal·cu·ra | cu | /mal.ˈku.ra/ |
| *Tenebris* | te·ne·bris | ne | /tɛ.ˈnɛ.brɪs/ |

> **统一规则：** 在实际开发中，所有词统一按倒数第二音节重读，减少记忆负担。

### 5.2 韵律结构

巨人语的韵律具有鲜明的仪式性特征：

#### 5.2.1 标准节奏

```
强 — 弱 — 强 — 停顿
```

#### 5.2.2 五音词组（核心韵律单元）

巨人语咒语和仪式语言中最核心的韵律结构为 **五音节词组**：

> **[三音词] + [二音词] = 5音节**

| 五音词组 | 音节划分 | 含义 |
|---------|---------|------|
| *Vulcruma Tanar* | vul·cru·ma + ta·nar | 强大·掌控 |
| *Malcura Dusrum* | mal·cu·ra + dus·rum | 黑暗·压迫 |
| *Surravet Omnua* | sur·ra·vet + om·nua | 升起·全能 |

#### 5.2.3 咒语吟唱节奏

咒语吟唱推荐采用以下节奏模式：

```
强 — 弱 — 强 — 弱 — 强 || 强 — 弱 — 停顿
```

例：

> *Vul·CRU·ma TA·nar || SUR·ra·vet OM·nua*
>
> （强大掌控 // 升起全能）

## 六、语法拓扑

### 6.1 语序

巨人语采用 **SOV（主语—宾语—动词）** 语序，符合古典拉丁语特征，营造古朴庄严感。

> **主语 — 宾语 — 动词**

| 巨人语 | 逐词翻译 | 整体含义 |
|--------|---------|---------|
| *Tu panum edanar* | 你·食物·吃（了） | 你吃了食物 |
| *Gigas malum vincit* | 巨人·邪恶·征服 | 巨人征服邪恶 |
| *Nos gloriam tenemus* | 我们·荣耀·持有 | 我们持有荣耀 |

### 6.2 名词结构

#### 6.2.1 常见词尾

| 词尾 | 语义倾向 | 示例 |
|------|---------|------|
| **-um** | 中性名词/物质名词 | *panum*（食物）、*vinum*（束缚） |
| **-a** | 阴性名词/抽象概念 | *gloria*（荣耀）、*vita*（生命） |
| **-us** | 阳性名词/施动者 | *servus*（仆人）、*magus*（智者） |
| **-or** | 抽象状态/性质 | *dolor*（痛苦）、*clamor*（呼喊） |
| **-men** | 工具/手段 | *nomen*（名字）、*lumen*（光） |
| **-culum** | 小型/工具/手段 | *vinculum*（束缚工具）、*oraculum*（神谕） |

#### 6.2.2 格系统（简化）

巨人语采用简化的格系统，仅保留三个核心格：

| 格 | 功能 | 词尾标记 | 示例 |
|----|------|---------|------|
| **主格** | 主语 | 原形 | *gigas*（巨人） |
| **宾格** | 直接宾语 | -m（阳性/阴性）/ -um（中性） | *gigantem*、*panum* |
| **属格** | 所属关系 | -is / -um | *gigantis*（巨人的）、*gigantum*（巨人们的） |

### 6.3 动词系统

#### 6.3.1 动词时态（简化三时态）

| 时态 | 后缀 | 示例（词根 *ed-* 吃） | 含义 |
|------|------|----------------------|------|
| **现在** | -at / -et / -it | *edat* | 吃（现在） |
| **过去** | -anar / -enar | *edanar* | 吃了 |
| **将来** | -abit / -ebit | *edabit* | 将吃 |

#### 6.3.2 动词变位模板

| 人称 | 现在时 | 过去时 | 将来时 |
|------|--------|--------|--------|
| **单数** | 词根 + -at | 词根 + -anar | 词根 + -abit |
| **复数** | 词根 + -ant | 词根 + -anant | 词根 + -abunt |

#### 6.3.3 常见动词词根

| 词根 | 含义 | 现在时 | 过去时 |
|------|------|--------|--------|
| *ed-* | 吃 | *edat* | *edanar* |
| *mor-* | 死 | *morat* | *moranar* |
| *ten-* | 持/有 | *tenet* | *tenenar* |
| *vinc-* | 征服 | *vincit* | *vincinar* |
| *duc-* | 引导 | *ducit* | *ducinar* |
| *dic-* | 说 | *dicit* | *dicinar* |
| *fac-* | 做/造 | *facit* | *facinar* |

### 6.4 否定与疑问

#### 6.4.1 否定

使用否定前缀 **ne-** 或 **ob-**：

| 前缀 | 语义 | 示例 | 含义 |
|------|------|------|------|
| **ne-** | 简单否定 | *ne·morat* | 不死 |
| **ob-** | 阻断/对抗性否定 | *ob·tenet* | 阻止/抵抗 |

#### 6.4.2 疑问

- 语序不变（保持 SOV）
- 句末语调上扬
- 可选在句首加疑问小词 *-ne*（附着于第一个词）

| 疑问形式 | 示例 | 含义 |
|---------|------|------|
| 语调上扬 | *Tu panum edanar?* ↗ | 你吃了食物吗？ |
| -ne 附着 | *Tune panum edanar?* | 你是否吃了食物？ |

### 6.5 代词系统

| 人称 | 单数 | 复数 |
|------|------|------|
| **第一人称** | *ego*（我） | *nos*（我们） |
| **第二人称** | *tu*（你） | *vos*（你们） |
| **第三人称** | *is*（他/她/它） | *ei*（他们） |

## 九、语义风格分层

### 9.1 风格层级

巨人语根据不同使用场景划分为三个风格层级：

| 层级 | 名称 | 使用场景 | 特征 |
|------|------|---------|------|
| **L1** | 碑文铭刻 | 石碑、建筑铭文、工程署名 | 简练、庄重、省动词 |
| **L2** | 仪式咒语 | 祭祀、咒语吟唱、誓言 | 韵律感强、五音词组、长元音 |
| **L3** | 日常记录 | 历史记载、书信、蓝图说明 | 完整句式、接近古典拉丁语 |

### 9.2 各层级语言特征

#### L1 碑文铭刻

```
[名词词组] + [属格修饰]
```

- 省略动词，以名词短语为主
- 结构紧凑，适合石面铭刻
- 例：*Gloria Gigantum*（巨人之荣）、*Manus Fabri Structura*（工匠之手·此建筑）

#### L2 仪式咒语

```
[三音词] + [二音词] + [三音词] + [二音词]
```

- 严格的五音词组韵律
- 长元音标记
- 重音分明，节奏固定
- 例：*Tenebris Manclor Moranar Ustrum*（黑暗囚笼·使生命止息）

#### L3 日常记录

```
[主语] + [宾语] + [动词]
```

- 完整的 SOV 语序
- 允许复合句和从句
- 使用完整时态系统
- 例：*Gigas malum magna cum sapientia vincit*（巨人以伟大的智慧征服邪恶）

## 十一、语言文化生态

### 11.1 语言地位

巨人语在信念森林地区的历史地位：

| 时期 | 地位 | 说明 |
|------|------|------|
| **巨人文明时期** | 主导语言 | 信念森林文明化程度最高的语言，有完整文字系统 |
| **落幕之日后** | 灭绝语言 | 无活体母语者，仅存于遗迹和残卷 |
| **现代（游戏时间）** | 考古语言 | 被探险家和学者部分破译，蘑菇人文化中保留碎片 |

### 11.2 语言对外影响

- **对蘑菇人：** 巨人语渗透到蘑菇人的生活和历史中。蘑菇人虽不能说巨人语，但部分蘑菇人通过临摹自学认识了巨人文字。蘑菇人将巨人语视为"高等文明的语言"。
- **对帕克索尔人：** 双方交往极少，帕克索尔人对巨人语几乎不了解。
- **对龙族：** 双方隔水而居，语言互不干涉。

### 11.3 文字系统

巨人族拥有自己独立的文字系统。文字特征（给美术团队的参考）：

| 特征 | 描述 |
|------|------|
| **风格** | 偏楔形文字，结构紧凑 |
| **笔画** | 直线为主，曲线为辅，体现机械感和力量感 |
| **排列** | 横向从左到右（与拉丁转写一致） |
| **载体** | 石碑铭刻、金属铭牌、建筑浮雕 |

### 11.4 语言禁忌与习俗

- **祖先名讳：** 不会直呼初代巨人王的名讳，使用专门的敬称词
- **工匠署名：** 在建筑完工时铭刻建造者姓名/纹章，是工匠文化的重要组成部分
- **誓言发语：** 在需要立誓或发愿的场合，以"愿祖先的勇气/智慧与我们相伴"发语
- **墓志铭：** 每位亡者的贡献铭刻在石头上，使用最庄重的 L1 碑文铭刻层级
